TaskPilot AI — Intelligent AI Task Management AgentAn Agentic AI-powered Task Management Application built using OpenAI Agents SDK, Node.js, Express.js, MySQL, and React.js.TaskPilot AI allows users to manage tasks through natural-language conversations. Instead of manually filling out forms, users can ask an AI agent to create, retrieve, update, or complete tasks.The AI agent understands user intent, selects appropriate tools, executes real database operations, and maintains conversation context across multiple interactions.This project was developed as a hands-on Agentic AI learning and portfolio project, focusing on AI agent architecture, function calling, persistent memory, guardrails, reliability, and automated evaluations. Key Features1. AI Agent with Intelligent Tool CallingBuilt using the OpenAI Agents SDK, with custom tools that allow the agent to interact with a MySQL database.Implemented tools:ToolDescriptioncreate_taskCreate new tasks using natural-language instructionsget_tasksRetrieve tasks with status and priority filtersupdate_taskModify existing task informationcomplete_taskMark tasks as completedprepare_delete_taskPrepare deletion requests requiring explicit confirmationThe agent automatically selects the appropriate tool based on user intent.Example interactions:"Create a high-priority task to implement JWT authentication.""Show me all my pending tasks.""Change task 5 priority to high.""Mark task 5 as completed.""Delete task 6."2. MySQL Database IntegrationImplemented real database operations using Node.js and MySQL.Features include:Parameterized SQL queriesTask status and priority managementPartial task updatesTask completion timestampsDatabase error handlingDuplicate task creation preventionTask data is stored persistently in MySQL.3. Persistent Conversation MemoryImplemented conversation memory using MySQL-backed sessions.Capabilities:Unique conversation IDsMulti-turn conversation supportPersistent user and assistant messagesStored tool calls and tool resultsConversation restoration after server restartFollow-up question handlingExample:User: Show me my pending tasks.Agent: Here are your pending tasks...User: What is the ID of the second task?Agent: The second task ID is 7.The agent uses previously stored conversation context to understand follow-up questions.4. Human-in-the-Loop Task DeletionImplemented a backend-controlled confirmation workflow for destructive operations.Deletion process:User requests task deletion.Agent invokes prepare_delete_task.Backend generates a short-lived confirmation token.User confirms the deletion through a separate API endpoint.Backend validates the token before deleting the task.This demonstrates the importance of separating AI decision-making from sensitive business operations.5. AI Guardrails and Input ValidationImplemented validation and guardrails using Zod and the OpenAI Agents SDK.Features include:Request payload validationRequired field validationInvalid date handlingConversation ID validationRestricted-input detectionInput guardrail enforcementStructured error responsesThese controls help prevent malformed requests and enforce application-level restrictions.6. Idempotency and ReliabilityImplemented idempotency to prevent duplicate task creation when the same operation is retried.Key concepts implemented:Client-generated idempotency keysMySQL unique constraintsRequest hashingDuplicate request detectionIdempotency conflict handlingStructured database operation errorsA retry using the same key and equivalent validated task parameters returns the existing task instead of inserting another record.7. Automated AI Agent EvaluationsBuilt an automated evaluation framework using Node.js's built-in test runner and MySQL assertions.The evaluation suite validates actual agent behavior rather than relying only on AI-generated responses.API validation and guardrail evaluations:Empty message rejectionInvalid conversation ID rejectionRestricted prompt handlingInstruction-bypass detectionTask retrieval response checksUnknown conversation handlingBehavioral and tool evaluations:EvaluationDescriptionEVAL-007Verify correct get_tasks selection and filtersEVAL-008Verify no unnecessary tool executionEVAL-009Verify create_task and MySQL INSERTEVAL-010Verify update_task and partial updatesEVAL-011Verify idempotent task completionEVAL-012Verify deletion preparation does not delete recordsEVAL-013Verify multi-turn conversation memoryLatest verified results:7/7 behavioral evaluations passed6/6 API smoke evaluations passed in an earlier runAutomatic database fixture cleanup implementedThe evaluations inspect tool selection, arguments, database side effects, and application behavior.8. React AI Chat InterfaceBuilt a React frontend using Vite and Axios.Features:Interactive AI chat interfaceNatural-language task managementConversation history sidebarNew Chat functionalitySwitch between previous conversationsActive conversation restoration after browser refreshLoading indicators and error handlingAutomatic idempotency-key generation for new submissionsThe frontend communicates with the Express backend through REST APIs.
